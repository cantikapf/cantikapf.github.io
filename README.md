## 💻 Technical Architecture

The portfolio is built using a custom **Dynamic Template Architecture** designed for high performance and maintainability:
- **Vanilla JavaScript Data Injection:** Replaced 24+ static HTML pages with a single `detail.html` master template that dynamically fetches content from a centralized `data.js` database via URL parameters.
- **Responsive Grid System:** Powered by a customized Bootstrap framework to ensure perfect rendering across mobile and desktop devices.
- **Rich Media Embeds:** Seamlessly integrates Tableau Dashboards, Google Slides iframes, and CSS-based browser mockups.
